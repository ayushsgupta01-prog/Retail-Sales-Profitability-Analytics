# Data Dictionary

| Column | Description | Business Meaning |
|---|---|---|
| Row ID | Unique row identifier | Identifies a dataset record |
| Order ID | Order identifier | Identifies the customer order |
| Order Date | Date order was placed | Used for time-based analysis |
| Ship Date | Date order was shipped | Used for shipping analysis |
| Ship Mode | Shipping method | Describes how the order was shipped |
| Customer ID | Customer identifier | Identifies the customer |
| Customer Name | Customer name | Identifies the customer |
| Segment | Customer segment | Groups customers by business segment |
| Country | Country | Geographic information |
| City | City | Geographic information |
| State | State | Geographic information |
| Postal Code | Postal code | Geographic information |
| Region | Region | Geographic grouping |
| Product ID | Product identifier | Identifies the product |
| Category | Product category | High-level product classification |
| Sub-Category | Product sub-category | Detailed product classification |
| Product Name | Product name | Identifies the product |
| Sales | Sales revenue | Revenue generated from the transaction |
| Quantity | Units sold | Number of units sold |
| Discount | Discount rate | Discount applied to the transaction |
| Profit | Profit | Profit generated from the transaction |
