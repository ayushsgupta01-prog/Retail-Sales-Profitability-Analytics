# Project Scope

## Project Title

Retail Sales & Profitability Analytics using SQL & Power BI

## Objective

Analyze retail transaction data using PostgreSQL and Power BI to
understand sales performance, profitability, product performance,
customer segments, regional performance, and the relationship between
discounting and profit.

## Business Questions

1. What are the overall sales and profit levels?
2. How do sales and profit change over time?
3. Which categories and sub-categories perform best?
4. Which products generate the most sales and profit?
5. Which products or sub-categories generate losses?
6. Which regions perform best?
7. Which customer segments generate the most revenue and profit?
8. How does discounting relate to profitability?
9. Which customers are the highest-value customers?
10. What business actions can be recommended from the analysis?

## Expected Outputs

- Validated PostgreSQL dataset
- SQL analytical queries
- Advanced SQL analysis
- CTE and window-function analysis
- Analytical SQL views
- One-page Power BI dashboard
- Business findings
- Business recommendations
- GitHub documentation
